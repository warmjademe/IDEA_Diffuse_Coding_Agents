# Third-party material

The archive's `third_party/attribution.json` maps all 155 development/formal tasks
to their source projects and copied license/notice files when found in the
checked-out versions. This covers 20+30 Python and 5+100 Java tasks. Code and
patch excerpts and developer tests remain subject to upstream rights; this
repository does not relicense them or grant rights absent upstream permission.

Python attribution uses source repository, PR/task identifier, base commit and
merge date. Java attribution uses Defects4J project/bug and the pinned framework
commit; Defects4J's project configuration identifies the underlying project and
buggy/fixed commits. Complete third-party project clones are not redistributed.

Some versions have no top-level license file; absence is recorded rather than
silently assigning an open-source license. Additional notices under standard
`META-INF` locations are included where present. Users should inspect the exact
upstream terms before reuse beyond inspection of these research results.

Only the current study's code contexts and execution evidence are released.
For the broader Python candidate pool, the package contains selection metadata
and source locations, not code for all 2,700 collected records.
