# Diffuse AI Control on LLM Code Review — Code Artifact

Code for the study *Diffuse AI Control on LLM Code Review: Adversarial Attack and
Defense of a Weak Checker*. It instantiates a red–blue Stackelberg game on LLM code
review: a strong untrusted generator writes reviews (benign or sandbagging), a cheap
weak checker scores them without the reference fix, and an objectively-anchored
ground-truth judge measures true quality.

## Layout
- `common/api.py` — minimal OpenAI-compatible chat wrapper (keys read from env).
- `collect_2026.py`, `build_dataset.py`, `build_context_v2.py` — contamination-resistant
  corpus collection (2026 bug-fix PRs) and task assembly.
- `run_phase*.py`, `run_hard_vs_soft.py`, `run_hvs_multi.py`, `run_coevolve.py`,
  `run_rq*.py` — experiment drivers for RQ1–RQ6.
- `scorers.py` — weak-checker rubrics (w0 vague / w structured / w_hard) and ground truth.
- `config.yaml` — roles and providers (no secrets).

## Credentials
All API keys are read from environment variables (e.g. `DEEPSEEK_API_KEY`,
`SHQBB_API_KEY`, `AIMONIKER_API_KEY`, `EASYMAX_GEMINI_KEY`, `GITHUB_TOKEN`) — none are
committed. Endpoint URLs for third-party OpenAI-compatible proxies are placeholders
(`YOUR_OPENAI_COMPATIBLE_ENDPOINT_*`); replace with your own. Host/notification
placeholders (`YOUR_NAS_HOST`, `YOUR_NAS_PASSWORD`, `YOUR_BARK_KEY`) likewise.

## Data & results
`data/` (collected corpus) and `results/` (experiment outputs) are generated by the
scripts and are not included in the repository.
